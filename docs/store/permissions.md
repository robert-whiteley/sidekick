# Permissions and Play declarations

What the release build asks for, why, and what Play Console needs. Checked from `app.json`, `modules/sidekick-native/android/src/main/AndroidManifest.xml` and the merged config (`npx expo config --type introspect`) on 25 Nov 2026. Every runtime permission is asked for in context, the first time a feature needs it, and can be refused without breaking the rest.

## Needs a Play Console declaration

### Foreground service types (App content → Foreground service permissions)

One service, `dev.sidekick.engine.ListenService`, declared `microphone|location|camera`. It starts only from the visible app, when the user turns listening or the live camera on. It shows a permanent notification with Stop while it runs. Types are added only when that permission is granted and that feature is on (`ListenService.kt`).

| Type         | Permission                                                                                                                 | Declaration text (paste)                                                                                                                                                                                                                                                                                                                                                                                       | Demo video must show                                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `microphone` | `FOREGROUND_SERVICE_MICROPHONE`                                                                                            | "Sidekick is a voice assistant. When the user turns on Listening, it keeps hearing for its wake word and transcribes conversations on the device, including with the screen off or another app open. The user starts it from the app, a permanent notification with a Stop button is shown the whole time, and stopping it ends all microphone use. Audio is processed on the phone and never uploaded."       | Open the app → tap Listen → the notification appears → lock the screen → say "Hey Sidekick, what time is it?" → it answers → pull down the notification → tap Stop → the mic indicator goes off. |

It runs with the screen off for hands-free use with a chest-mounted or USB camera. The user turns it on in the app; the notification shows that the camera is on and has a Stop button. Location is only read while that user-started service runs and never leaves the phone."                                                                                         | With location allowed, start Listening → walk/drive briefly → ask "Where was I when I talked to Sam?" or open Memory → the moment shows the town.                                                |

A second service, `RoutineTaskService`, is declared `shortService` (`FOREGROUND_SERVICE` only; no extra type permission). It runs a user-created routine (for example "every day at 6 pm, recap my day") when its time or trigger comes while the app is closed, for at most ~3 minutes, then stops. Declaration text: "Runs a routine the user created in the app (a scheduled recap, briefing or reminder check) at the time they chose, on the device, and stops when it finishes." Video: create a routine by voice, close the app, show the notification with its result.

`mediaPlayback` is **not** used any more: expo-audio added a playback service by default. It is now off (`["expo-audio", { "enableBackgroundPlayback": false }]`), because saved clips play only inside the app. If the reviewer still sees it, the build predates this change.

Risk: Play may ask why `location` is needed in the service. Fallback if refused: drop the `location` type and tag moments only while the app is open.

### Set alarms and timers in Clock

- `com.android.alarm.permission.SET_ALARM`: lets Sidekick hand an alarm or timer the user asked for to the Clock app. Install-time, no prompt; without it Clock refuses (found on the Pixel 5, 25 Nov).

### Exact alarms

- `SCHEDULE_EXACT_ALARM` (declared in `app.json`): reminders at the time the user set. It is user-granted. On Android 14+ it is off by default for new installs. Play's exact-alarm policy restricts only `USE_EXACT_ALARM`, which we do **not** use, so no form is needed. The App content questionnaire may still ask "core functionality"; answer: "Reminders the user approves, delivered at the chosen minute." Phone check: with the permission off, reminders must still fire, perhaps a few minutes late.

## Removed or blocked on purpose

| Permission                                                                                                              | Why removed                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`, `READ_MEDIA_AUDIO`, `READ_MEDIA_VISUAL_USER_SELECTED`, `ACCESS_MEDIA_LOCATION` | Added automatically by expo-media-library. Play's Photo and Video Permissions policy allows broad photo access only for core gallery-type apps, so Sidekick would be rejected. Saving a clip or photo to the gallery is a write, which Android 10+ allows without these. **Phone check needed:** Save in the moment player (`MomentPlayer.tsx`, `requestPermissionsAsync(true, …)` write-only) still works on Android 13+ |
| `SYSTEM_ALERT_WINDOW`                                                                                                   | Unused (added by the default template)                                                                                                                                                                                                                                                                                                                                                                                    |
| `WRITE_CONTACTS`                                                                                                        | Sidekick never edits contacts                                                                                                                                                                                                                                                                                                                                                                                             |
| `MANAGE_EXTERNAL_STORAGE`                                                                                               | Never needed; folders come through the system folder picker. `READ/WRITE_EXTERNAL_STORAGE` stay only up to Android 12 (`maxSdkVersion 32`, from expo-media-library) for saving to the gallery on older phones                                                                                                                                                                                                             |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK`                                                                                     | See above                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SMS, call log                                                                                                           | Not used: one Google Play app, and messages go through the user's messaging apps                                                                                                                                                                                                                                                                                                                                          |
